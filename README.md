**FAQ**

**Q: 手柄操作影响我正在玩的游戏怎么办？**
A: 用 ViGEmBus 作者亲手制作的 [HidHide](https://github.com/nefarius/HidHide)，把虚拟手柄藏起来，让正在玩的游戏以为它不存在。挂机和打游戏两不误，堪称时间管理大师。

**Q: 报错了怎么办？**
A: 淡定。脚本出错时错误会写进 `error.log`，看一眼，改一行，又是一条好汉。

**Q: 怎么退出？**
A: 配置页按 `Esc`，运行页按 `Esc` 停任务回配置页，全局 `Ctrl+C` 兜底。总有一款适合你。
